# 条形码与 RFID 识别方案对比分析

传感与测试技术课程作业：自动识别技术的原理、流程与效率对比

## 内容说明

报告从自动识别技术的角度，对比**传统条形码**与 **RFID** 两套方案：

- 技术原理与系统组成
- 作业流程差异
- 识别效率与适用场景对比
- 系统结构示意

## 目录结构

```
RFID.tex / RFID.pdf     报告 LaTeX 源码与成品
图1_传统条码流程图.py     生成条码作业流程图的脚本
图2_RFID系统结构示意图.py  生成 RFID 系统结构图的脚本
图3_RFID数据读取流程图.py  生成 RFID 数据读取流程图的脚本
a.py                    辅助脚本
*.png                   脚本生成的插图
```

## 工具

XeLaTeX · Python（matplotlib 绘图）

## 复现提示

先运行三个 `图*.py` 生成插图，再用 XeLaTeX 编译 `RFID.tex`。
